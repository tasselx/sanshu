## 2. 真正的「多开 / 空转 request」记录（共 6 条，3 类根因）

### 类型 A：fable-5 上游 provider error（3 条：#1 #2 #9）
- 特征：`claude-fable-5` 模型，启动后 1–2.5s 即 `rpc.run error=true`，**0 迭代 0 工具**。
- 与 6/11 报告第 4 节同根：上游临时故障 "We're having trouble connecting to the model provider"。
- 这类通常 0-token、**多半不计费**，但会让你连点「继续/重试」，每点一次就是一条新 request 记录。

### 类型 B：sanshu stop-hook 自动注入续跑（1 条：#11 ab1d19c5）——**自伤型多开**
这是本次扫描最值得修的一条，**证据来自 Luma 会话 `7c04f28f` 的 transcript 原文**：
- 第 13 行：`{"type":"turn_ended","status":"error","error":"User aborted request"}` —— #10 是**用户手动点了停止**。
- 第 14 行：紧接着出现一条 user 消息：`⚠️ 强制交互违规检测：本轮 turn 调用了 sanshu MCP 工具，但没有以 zhi 收尾确认就要结束…` —— 这是 **stop-hook 自动注入的 followup**，它**把一个被用户主动中止的 turn 又拉起来**，生成了 #11 `ab1d19c5`（= 6/13 截图里的「32.7万」行）。
- 即：用户手动停 → hook 判定「调了 sanshu 没 zhi 收尾」→ 注入续跑 → **凭空多一条计费 request**。机理与 6/11 报告第 3 节、第 8 节（hook v6/v7）完全同构。
- 第 18、19 行：之后还有连续两条 `User aborted request`。

> 注：#11 这条 hook 续跑实际上跑出了有用的诊断并正确收了 zhi（transcript 15–16 行），但它仍是「用户没主动发起」的一条额外 request。**当用户是“手动中止”时，hook 不应再注入续跑**——这是 hook 逻辑值得收紧的点。

### 类型 C：用户手动中止（#10 #13）
- #10 `b380fce6`：跑了一半（20 迭代）被用户停。
- #13 `5e8567f7`：基本空转后被停（6s）。
- 这类是用户自己停的，属正常操作；但配合类型 B 的 hook 注入，会在面板上堆出「同一会话短时间多行」的观感。

## 4. 结论与建议

**两天真正“多开/空转”的只有 6 条，集中在 3 类**：
1. **fable-5 provider error ×3**（凌晨 01:43、下午 15:06）——上游抖动，建议这类报错**别连点继续**，等一会或直接换 opus/其它家族。
2. **sanshu hook 注入 ×1**（Luma 15:09 那条 32.7万）——**自伤**，建议改 hook：**检测到 `error="User aborted request"`（用户主动中止）时直接放行，不要注入续跑**。这是本仓库可立即修的点。
3. **用户手动中止 ×2**——正常操作。

**没有发现 Opus 工具调用 XML 文本泄漏**（6/11 的主因）在 6/13–6/14 复现：Luma transcript `<invoke` 字面 0 处，jable/PagePick 的工具都是真实执行。说明 6/11 之后那条主因这两天没再触发。

**识别口径**（面板多行≠多开）：永远以 `cursor.requestTraces.log` 的 `agent.request` span 数 + requestId + composerId 三层核对；同 requestId 多行=一条的多次用量批次，不同 composerId=不同会话(可能并行)，用户主动 abort 或 hook 注入才是真·多开。

## 5. 修复（类型 B）：stop hook v8 —— 手动中止不再注入续跑

- 文件：`scripts/cursor-hooks/check-zhi-on-stop.sh`（仓库源；部署副本 `~/.cursor/hooks/check-zhi-on-stop.sh` 为独立拷贝，需同步后生效）。
- 改动：在主判定之前新增 v8 判定块——读取本轮 transcript 最后一个 `turn_ended`，若 `error` 为 **"User aborted request"**（用户手动点停止）则**直接 `allow` 放行**，不再走 `block_sanshu` 注入续跑。
